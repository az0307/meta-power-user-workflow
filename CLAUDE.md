**Meta Power User Tricks & Workflow** is a **documentation-only** repository. It is a single curated `README.md` guide covering power-user productivity and AI-automation practices — there is no application code, build system, or tests.

The entire repo is `README.md`, organized into these sections:

- **AI Tab Organization Strategies** — content-based/automated browser tab grouping.
- **Calendar-Driven Productivity Systems** — time-blocking, the T.A.C.O framework (Terminate, Automate, Consolidate, Outsource), AI-generated agendas.

- **Meta Tips for Power Automation** — including Comet Browser workflows.
- **Actionable Next-Action Prompts** — reusable prompt snippets.
- **Links and Resources.**
